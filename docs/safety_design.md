# Safety Design

## Structural vs. Advisory Controls

### Advisory Controls
These include:
- The LLM system prompt.
- Instructions asking the model to avoid unsafe actions.
- Descriptions explaining when tools should be used.

**Why they are insufficient**: Advisory controls rely on the statistical probability of the model obeying, rather than a physical system constraint. Complex prompts or adversarial input can override them.

### Structural Controls
This project implements safety through the following deterministic, hardcoded structural controls:
1. **LangGraph Conditional Routing**: Evaluates the `check_trust_node` output and routes any low-trust action batch into a `human_review_node`, physically preventing traversal to the execution phase.
2. **Deterministic Trust Limits**: Trust metrics are queried dynamically from SQLite, never generated by the LLM itself, preventing hallucinations of trust levels.
3. **Reversible Mutations**: Pre-mutation states are collected via direct SQLite SELECT commands and serialized independently of the LLM plan.
4. **Tool Restrictions**: The tools provided via LangGraph bind essentially dummy actions for the agent to express intent, completely isolating SQL logic from AI token generation.
5. **Human-in-the-Loop Interrupts**: Relies on LangGraph's native `interrupt` functionality to halt a graph thread. Execution waits for the user to explicitly call resume with permission.
